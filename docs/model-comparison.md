> 작성 최현영 · 11/25 멘토링 후속 ("단순 기준과 비교해 모델의 가치를 숫자로 보여 줄 것", 성별별 지표·신뢰구간).
> 실행: `uv run --env-file envs/.local.env --group ml python -m ml.compare` ([ml/compare.py](../ml/compare.py)). 결과는 MLflow `compare:<model_version>` run에도 기록.
> 원본 데이터는 레포에 없고, 이 문서는 집계 숫자만 담음.

## 조건
- 데이터: 국민건강영양조사 2022~2024 SAS 원본 (원본 sha256은 MLflow 태그), 대상·정답은 [ml/README.md](../ml/README.md) 기준
- 분할: `train.py`와 같은 함수(`select_target`·`build_xy`), 층화 80/20, 시드 42 → 서버 모델 v1과 같은 평가 세트
- 비교 모델
  - `logistic`: 서버 모델(입력 12개, 표준화 + 로지스틱)
  - `age_only`: 나이만 / `age_bmi`: 나이 + BMI (단순 기준)
  - `xgboost`: 입력 12개, 얕은 트리(깊이 3, 300그루, 튜닝 없음)
- 신뢰구간: 평가 세트 부트스트랩 1,000번(시드 42), 95% 백분위. "로지스틱 대비 차이"는 같은 표본에서 짝지어 계산
- 위험 단계 지표: 서버와 같은 30/60 기준 (`evaluate.level_metrics`)

## 해석
1. **단순 기준보다 낫다**: 두 질환 모두 나이만·나이+BMI보다 AUROC가 높고, 차이의 신뢰구간이 0 아래.
   - 고혈압은 차이가 큼(나이만 −0.154, 나이+BMI −0.056) → 가족력·음주 문항이 실제로 값을 함
   - 당뇨는 BMI가 대부분을 설명하고 나머지 문항의 추가 이득은 작음(나이+BMI −0.012, 신뢰구간 −0.023~−0.001). 작지만 0보다는 확실히 아래
2. **XGBoost와 차이가 없다**: 당뇨 +0.001, 고혈압 −0.009, 둘 다 신뢰구간이 0을 걸침 → 성은님 노트북(11/24) 결과를 레포 코드로 재현. 보정 기울기는 로지스틱이 1에 더 가깝거나 비슷하고, 계수로 요인·건강 나이를 설명할 수 있어서 **로지스틱 유지**
3. **성별별로 보면 낮아진다**: 당뇨 남 0.704 / 여 0.760, 고혈압 남 0.690 / 여 0.686. 전체 AUROC에는 "성별 자체의 위험 차이"가 섞여 있어서, 같은 성별 안에서 구분하는 힘은 0.69~0.76으로 보고하는 게 정직함
4. **위험 단계 쓸모**: 주의 이상(30점↑)이 실제 위험자의 당뇨 88.6%, 고혈압 70.2%를 잡고, 높음(60점↑)은 3명 중 2명꼴로 실제 위험(당뇨 67.1%, 고혈압 64.4%)

## 한계
- 평가 세트 하나(20%)에서의 부트스트랩이라 표본 변동만 반영. 다른 연도·외부 데이터 검증은 안 함
- XGBoost는 튜닝하지 않음 (튜닝하면 약간 오를 수 있지만, 지금 차이로는 설명 가능성을 포기할 이유가 없음)
- 정답이 "전단계 이상"이라 위험 비율이 높음 → 점수가 높게 보이는 이유 (보정은 잘 맞음, 기울기 1.06)
- 자가 설문 입력만 쓰는 모델이라 검진 수치를 쓰는 모델보다 AUROC가 낮은 건 예상된 범위
