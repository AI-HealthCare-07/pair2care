# 요구사항 정의서 (초안)

> 상태: **초안** — 11/16 팀장 작성, 11/17 팀 회의에서 고치고 확정함  
> 근거: 주제 원문 [topic_talos.md](topic_talos.md), 페르소나 [personas.md](personas.md)

## 1. 문제 정의
- 배경: 건강검진에서 혈압·혈당 **경계 판정**을 받아도 아직 진단 전이라 병원 관리 대상이 아님. 병원 방문은 2~3개월 간격이라 일상 식단·운동 피드백을 받을 곳이 없음
- 사용자가 막히는 지점
  - 무엇부터 바꿔야 할지 모름 (매일 먹는 메뉴, 간식)
  - 기록이 번거로워 며칠 만에 포기함 (메뉴·양을 일일이 입력)
  - 혼자 세운 계획은 일·근무 일정에 밀려 작심삼일이 됨
  - 고정 시간 알림이 교대 근무·회식 같은 실제 생활과 안 맞음
  - 노력의 결과(위험도 변화)가 눈에 보이지 않아 동기가 떨어짐
- 목표 (한 줄 후보): **고혈압·당뇨 위험 단계의 사용자가 사진 한 장과 짝꿍 한 명으로 생활습관을 바꾸고, 위험도 변화를 직접 확인하게 함**

## 2. 타깃 사용자
- **11/17 확정**: 일하는 시간이 불규칙한 30~60대(사무직·자영업·현장직), 정상(예방)~경계 단계까지 (진단 전)
- 대표 사용자 후보: 김지은(당뇨 위험, 식단), 박성호(고혈압 위험, 걷기·교대 근무) — 상세는 [personas.md](personas.md)

## 5. 사용자 시나리오

### 김지은 (당뇨 위험, 식단)
1. 가입 후 건강 프로필 설문 → 당뇨 위험도 "주의" 확인 (REQ-PROF-001, REQ-PRED-001)
2. 점심 배달 음식 사진 업로드 → "제육덮밥" 인식, 1인분 선택 (REQ-FOOD-001, REQ-FOOD-002)
3. "탄수화물·당류가 하루 권장량의 60%" 피드백 + "다음엔 밥 반 공기로 바꿔보기" 추천 (REQ-LLM-002, REQ-FOOD-003)
4. "오후 단 커피 대신 아메리카노 주 3회" 챌린지 참여, 완료 체크 (REQ-CHAL-001, REQ-CHAL-002)
5. 4주 뒤 재설문 → 대시보드에서 당뇨 위험도가 내려간 추이 확인 (REQ-PRED-004, REQ-DASH-003)

### 박성호 (고혈압 위험, 걷기·교대 근무)
1. 가입 후 설문 → 고혈압 위험도 "주의" 확인 (REQ-PROF-001, REQ-PRED-001)
2. 동료를 짝꿍으로 초대 → "주 3회 10분 걷기" 짝꿍 챌린지 시작 (REQ-PAIR-001, REQ-PAIR-002)
3. 이번 주 근무표에 맞춰 알림 요일·시간 설정 (REQ-NOTI-001)
4. 쉬는 시간에 걷고 완료 체크 → 짝꿍의 완료 기록 확인·응원 (REQ-CHAL-002, REQ-PAIR-003, REQ-PAIR-004)
5. 재측정 혈압 입력 → 대시보드에서 혈압 기록과 위험도 추이 확인 (REQ-DASH-001, REQ-DASH-003)

- [ ] 타깃을 위험 단계만 할지, 정상 범위 예방 단계까지 넓힐지
- [ ] 짝꿍 챌린지(REQ-PAIR-001, REQ-PAIR-002)를 필수로 둘지 — 원문상 챌린지는 자유 구현이라 필수 챌린지 안에 넣을 수 있음
- [ ] 건강 기록(REQ-006)의 혈압·혈당 값을 예측 입력에도 쓸지 → 데이터셋 컬럼에 따라 결정
- [ ] **걸음 수 연동 방법**
  - 기본: 수동 입력·완료 체크 (모든 폰)
  - 추가 후보 ①: 아이폰 단축어 자동화 → 매일 건강 앱 걸음 수를 우리 API로 전송 (걸음 수 수신 API + 개인 토큰만 필요, 아이폰 한정)
  - 추가 후보 ②: 걸음 수 화면 캡처 → CLOVA OCR로 숫자 인식 (모든 폰, 결과지 OCR과 재사용)
  - 제외: 별도 모바일 앱 개발 (6주 범위 초과)
- [ ] **타깃 연령대**: 30~50대 직장인(김지은·박성호) vs 60대 은퇴 부부(이지희) — 둘 중 하나로 좁혀야 화면·문구·알림 방향이 정해짐
- [ ] 예측 대상: 고혈압·당뇨 각각 vs 대사증후군 위험도(성은님 이수정) — 데이터셋 컬럼 보고 결정
- [ ] **범위 덜어내기**: 산책 장소·후기, 복약, 가족 연결·효도 리워드, 외부 캘린더 연동은 6주 안에 어려움 → 아이디어 보관함으로 둘지
