# 요구사항 정의서 (초안)

> 상태: **초안** — 11/16 팀장 작성, 11/17 팀 회의에서 고치고 확정함  
> 근거: 주제 원문 [topic_talos.md](topic_talos.md), 페르소나 [personas.md](personas.md)

## 1. 문제 정의
- 배경: 건강검진에서 혈압·혈당 **경계 판정**을 받아도 아직 진단 전이라 병원 관리 대상이 아님. 병원 방문은 2~3개월 간격이라 일상 식단·운동 피드백을 받을 곳이 없음
- 사용자가 막히는 지점
  - 무엇부터 바꿔야 할지 모름 (매일 먹는 메뉴, 간식)
  - 기록이 번거로워 며칠 만에 포기함 (메뉴·양을 일일이 입력)
  - 혼자 세운 계획은 일·근무 일정에 밀려 작심삼일이 됨
  - 고정 시간 알림이 교대 근무·회식 같은 실제 생활과 안 맞음
  - 노력의 결과(위험도 변화)가 눈에 보이지 않아 동기가 떨어짐
- 목표 (한 줄 후보): **고혈압·당뇨 위험 단계의 사용자가 사진 한 장과 짝꿍 한 명으로 생활습관을 바꾸고, 위험도 변화를 직접 확인하게 함**

## 2. 타깃 사용자
- **11/17 확정**: 일하는 시간이 불규칙한 30~60대(사무직·자영업·현장직), 정상(예방)~경계 단계까지 (진단 전)
- 대표 사용자 후보: 김지은(당뇨 위험, 식단), 박성호(고혈압 위험, 걷기·교대 근무) — 상세는 [personas.md](personas.md)

## 4. 비기능 요구사항
- 예측·추천 결과는 참고값으로만 표시하고 "진단", "발병 확정" 표현을 쓰지 않음. 예측·추천 화면에 "의료 진단이 아니며 전문가 상담 필요" 안내를 붙임
- LLM 추천은 공인 가이드(질병관리청 등) 근거 안에서만 답함
- LLM 추천·식단 분류처럼 몇 초 걸리는 작업은 비동기(Redis Stream + AI 워커)로 처리하고 결과는 SSE로 전달함
- 개인 건강정보는 로그에 남기지 않고, 실제 환자 데이터는 사용하지 않음
- 위험도가 높게 나오면 말투 설정과 관계없이 보건소·병원 검사를 권함
- 안내 말투는 쿠션어를 쓴 응원형으로 통일함 (11/17)
- 걸은 횟수 등 실천 기록만으로 "위험이 줄었다"고 표시하지 않음 (11/17)
- 식단 사진 없이도 핵심 흐름(설문 → 예측 → 챌린지 → 대시보드)이 돌아가야 함
- 큰 글씨·큰 버튼 등 접근성 고려 — 타깃에 60대 포함(11/17)으로 **필수**, 기준 수치는 와이어프레임 때 정함
- 걸음 수: 우선 직접 입력(11/17), 연동은 재검토. 웹 브라우저는 건강 앱(아이폰 건강, 헬스 커넥트·삼성헬스) 데이터를 직접 읽을 수 없음 → 기본은 수동 입력·완료 체크, 추가로 "거의 자동" 방법 검토 (논점)

## 5. 사용자 시나리오

### 김지은 (당뇨 위험, 식단)
1. 가입 후 건강 프로필 설문 → 당뇨 위험도 "주의" 확인 (REQ-002, 003)
2. 점심 배달 음식 사진 업로드 → "제육덮밥" 인식, 1인분 선택 (REQ-013, 014)
3. "탄수화물·당류가 하루 권장량의 60%" 피드백 + "다음엔 밥 반 공기로 바꿔보기" 추천 (REQ-012, 015)
4. "오후 단 커피 대신 아메리카노 주 3회" 챌린지 참여, 완료 체크 (REQ-008, 009)
5. 4주 뒤 재설문 → 대시보드에서 당뇨 위험도가 내려간 추이 확인 (REQ-004, 005)

### 박성호 (고혈압 위험, 걷기·교대 근무)
1. 가입 후 설문 → 고혈압 위험도 "주의" 확인 (REQ-002, 003)
2. 동료를 짝꿍으로 초대 → "주 3회 10분 걷기" 짝꿍 챌린지 시작 (REQ-010)
3. 이번 주 근무표에 맞춰 알림 요일·시간 설정 (REQ-016)
4. 쉬는 시간에 걷고 완료 체크 → 짝꿍의 완료 기록 확인·응원 (REQ-009, 010)
5. 재측정 혈압 입력 → 대시보드에서 혈압 기록과 위험도 추이 확인 (REQ-005, 006)

## 6. 11/17 회의 논점

### 결정 (11/17)
- 타깃: 30~60대, 일하는 시간이 불규칙한 사람(사무직·자영업·현장직), 정상~경계 단계
- 입구: 가입 중에 설문·검진 수치 둘 다 받음(수치는 선택, 이탈 주의). 가입 후 정보 변경에서 추가 입력·수정 가능
- 예측: 설문만 있을 때 / 수치까지 있을 때 둘 다 동작해야 함
- 짝꿍 챌린지 필수, 짝꿍에겐 완료 여부만 공유 (상세 공유 범위는 추후 논의)
- 대시보드: 혈압(집에서 잰 값만)·혈당·음주·운동량 그래프 + 달성률. 검진 수치는 대시보드에 섞지 않음
- 말투: 쿠션어(응원형). 걸음 수: 직접 입력
