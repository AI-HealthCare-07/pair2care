## 건너뛰기 저장 요약
| 상황 | 건너뛰는 문항 | 저장 코드 |
|---|---|---|
| 음주 경험 "없다" (BD1 = 1) | 11 / 12 / 13 | 8 / 8 / 8 |
| 음주 빈도 "전혀" (BD1_11 = 1) | 12 / 13 | 8 / 8 |
| 평생 흡연 "피운 적 없음" (BS1_1 = 3) | 15 / 16 | 8 / 888 |
| 현재 흡연 "지금은 안 피움" (BS3_1 = 3) | 16 | 888 |

- 피운 적 없는 사람의 현재 흡연은 8(비해당). 3은 "과거엔 피웠으나 지금은 안 피움"이라 다른 뜻

## 재설문 규칙 (주 1회)
- 재설문은 새 행으로 쌓음. "안 물음" 항목(키·가족력·전자담배 등)은 직전 값 복사 → 최신 행 하나가 항상 완전한 모델 입력
- 음주 10→11→12·13, 흡연 14→15→16: 상위 답이 바뀌어 건너뛰기 상태가 달라진 하위 문항만 처리
  - 안 묻던 문항이 해당되면(예: 비흡연 → 매일 흡연) 다시 물음
  - 묻던 문항이 해당 안 되면(예: 흡연 → 금연) 8 / 888 자동 저장
  - 13·16번은 계속 해당이면 다시 묻지 않고 직전 값 복사
- 허리둘레: 안 적으면 복사 없이 빈칸, 측정일은 그 행의 created_at

## 저장 규칙
- 건너뛴 문항은 빈칸(NULL)이 아니라 위 "건너뛰기" 코드로 자동 저장
- 예외: 21번 임신 여부는 남성에게 묻지 않아 빈칸(NULL)으로 저장 (우리 문항이라 국건영 코드 없음)
- 비해당 8 / 888은 "안 함·없음·해당 없음"의 뜻으로 그대로 저장 (결측 아님)
- 모름(9)은 가족력에만 있음 → 모델에서는 결측으로 처리
- 음주·흡연은 국건영에 모름(9)이 있지만 "모름" 보기 없이 필수 응답 (원자료의 모름·무응답은 1.6% 정도로, 문항별 모름보다 영역 전체 무응답으로 보임)
- 하루 흡연량 888은 학습 때 0개비로 변환
- 가족력은 0 / 1 / 9 / 8을 저장하므로 참·거짓이 아님 → 컬럼 이름에 `is_`를 붙이지 않음 (예: `father_diabetes_history`)

## 기록·챌린지용 문항 (예측 안 씀)
> 예측에 안 쓰므로 국건영 코드 대신 우리 코드로 저장. 모두 선택
> 주 1번 "지난 1주일 평소" 기준으로 받음 → health_logs (log_type), measured_at = 그 주 월요일 00:00 (KST), 한 주에 한 줄(다시 입력하면 덮어쓰기)
> 보기는 국건영 문항을 참고함

| 문항 | log_type | 답 형태·화면 보기 | 참고 변수 | 저장 값 (value / value2) | 단위 |
|---|---|---|---|---|---|
| 걷기 일수 | WALK_DAYS | 전혀 하지 않음 / 1일 … 6일 / 7일(매일) | BE3_31 | 0~7 | days_per_week |
| 근력운동 일수 | STRENGTH_DAYS | 전혀 하지 않음 / 1일 … 4일 / 5일 이상 | BE5_1 | 0~5 (5 = 5일 이상) | days_per_week |
| 앉아 있는 시간 | SITTING_HOURS | 숫자 | BE8_1 | 0~24 | hours_per_day |
| 수면 시간 | SLEEP | 숫자, 주중·주말 각각 | BP16_1, BP16_2 | 주중 / 주말 | hours_per_day |
| 아침식사 빈도 | BREAKFAST | 거의 안 함 / 주 1~2회 / 주 3~4회 / 주 5~7회 | L_BR_FQ | 0 / 1 / 2 / 3 | — |
| 스트레스 | STRESS | 거의 안 느낌 / 조금 / 많이 / 대단히 많이 | BP1 | 0 / 1 / 2 / 3 | — |

- 아침식사·스트레스는 숫자가 클수록 "더 자주·더 많이" (국건영 코드와 순서 반대, 그래프용)
- 뺀 것: 유산소 운동 실천(pa_aerobic, 여러 문항으로 계산하는 값이라 걷기·근력으로 대신), 근무 형태·경제활동·주당 근로시간(쓰는 기능이 없음)
