## 건너뛰기 저장 요약
| 상황 | 건너뛰는 문항 | 저장 코드 |
|---|---|---|
| 음주 경험 "없다" (BD1 = 1) | 11 / 12 / 13 | 8 / 8 / 8 |
| 음주 빈도 "전혀" (BD1_11 = 1) | 12 / 13 | 8 / 8 |
| 평생 흡연 "피운 적 없음" (BS1_1 = 3) | 15 / 16 | 8 / 888 |
| 현재 흡연 "지금은 안 피움" (BS3_1 = 3) | 16 | 888 |

- 피운 적 없는 사람의 현재 흡연은 8(비해당). 3은 "과거엔 피웠으나 지금은 안 피움"이라 다른 뜻

## 저장 규칙
- 건너뛴 문항은 빈칸(NULL)이 아니라 위 "건너뛰기" 코드로 자동 저장
- 비해당 8 / 888은 "안 함·없음·해당 없음"의 뜻으로 그대로 저장 (결측 아님)
- 모름(9)은 가족력에만 있음 → 모델에서는 결측으로 처리
- 음주·흡연은 "모름" 보기 없이 필수 응답 (원자료의 모름·무응답은 1.6% 정도로, 문항별 모름보다 영역 전체 무응답으로 보임)
- 하루 흡연량 888은 학습 때 0개비로 변환
- 가족력은 0 / 1 / 9 / 8을 저장하므로 참·거짓이 아님 → 컬럼 이름에 `is_`를 붙이지 않음 (예: `father_diabetes_history`, 최종 이름은 ERD 기준)

## 기록·챌린지용 문항 (예측 안 씀)
> 예측에 안 쓰므로 국건영 코드 대신 실제 값으로 저장. 모두 선택. 재설문이 아니라 일일·주간 기록 화면에서 받음

## 확인 중
- 문항 문구와 질문 대상: 이용지침서 원문으로 확인 필요 (코드는 확인 끝남)
- 19~20번 진단 여부: 팀 의견 받는 중

## 이 표에 없는 것
- 검진 수치(혈압·공복혈당·당화혈색소·콜레스테롤 등): checkup_records, 선택 입력. 수치가 있으면 기준표로 판정
