## 2. 추가 제안 근거

### A. 중성지방·HDL 콜레스테롤 (검진 수치) — **우선 높음**
- 팀 결정: "대사증후군은 검진 수치가 있으면 기준표로 판정"
- **문서끼리 어긋남**: survey-mapping.md 마지막 줄은 검진 수치를 "혈압·공복혈당·당화혈색소·콜레스테롤 등"으로 적었는데, erd.dbml `checkup_records`에는 혈압·공복혈당·허리둘레만 있음 → 이 제안으로 두 문서를 맞춤
- 그런데 대사증후군 기준 5개 중 2개(**중성지방 ≥150, HDL 남 <40·여 <50**)가 지금 `checkup_records`에 없음 → 5개 중 3개만으로는 "3개 이상 해당" 판정을 제대로 못 함 (허리·혈압·혈당이 모두 정상일 때만 "아님"을 확정할 수 있음)
- 국가건강검진 결과지에 이상지질혈증 항목(총콜레스테롤·HDL·중성지방·LDL)이 있어 사용자가 옮겨 적을 수 있음 (검사 대상 연령·주기는 공단 기준 확인 필요). OCR(S-08)로 읽을 때도 같은 칸이 필요
- 비용: `smallint null` 컬럼 2개 + 입력 화면 칸 2개

### B. 근력운동 일수 → 예측 입력? — **논의만 (ERD 요청에 안 넣음)**
| 지표 | 고혈압 | 당뇨 |
|---|---|---|
| 하루 늘 때 오즈비 (로지스틱, 기본 변수 보정) | 0.946 (0.916~0.976) | 0.946 (0.920~0.973) |
| AUC 추가 효과 | +0.001 | +0.001 |
| 근력운동 0일인 사람 비율 | 73% | 73% |
| 0일 → 주 3일 바꿀 때 점수 변화 (0일인 사람 평균) | −3.1점 | −3.4점 |
| 비교: 체중 −3kg | −2.5점 | −3.5점 |
| 비교: 음주 월 1회 이하로 | −1.7점 | −1.0점 |
| 비교: 금연 | **0.0점** | −1.0점 |

- 성은님 실험(HistGB)과 같은 결론: **AUC는 안 오름**. 다만 로지스틱 계수로는 두 질환 모두 보호 방향이 신뢰구간상 확실
- 넣으면 좋은 점: S-10에서 "운동"을 바로 고를 수 있고, 타깃 73%가 0일이라 바꿀 여지가 큼
- **넣지 않는 게 나은 이유 (현재 결론)**
  - 팀 결정(데이터셋 진행 상황 8장): "위험도를 바꾸는 생활 요인은 체중·음주·흡연", 운동 챌린지는 "운동 → 체중 관리" 경로로 설명
  - 서비스 방향 아이디어(11/18): 위험도가 걸음 수·운동 기록으로 안 움직이는 게 **부풀려지지 않는 성과 지표** → 스스로 답하는 운동 일수를 넣으면 "주 5일"이라고만 답해도 위험도가 내려가 이 장점이 사라짐
- **대안**: 모델은 그대로 두고 S-10에서 "주 3회 운동 + 체중 2kg 감량 시"처럼 **운동을 체중 변화로 이어서** 미리보기 → 팀 결정과 맞고 챌린지 연결도 유지
- 금연 결과는 그대로 유효: **고혈압 위험도는 금연해도 거의 안 바뀜** → S-10 화면 처리 필요

### C. 당화혈색소 (검진 수치, 선택) — 우선 중간
- 당뇨 정답 기준이 "공복혈당 100 이상 **또는** 당화혈색소 5.7 이상" (데이터셋 진행 상황 3-1) → 공복혈당만으로는 기준표 판정이 정답 정의와 반쪽만 맞음
- 일반 국가검진엔 보통 없고 회사·종합검진에 있음 → 있으면 받는 선택 칸
- 총콜레스테롤·LDL은 성은님 의견대로 넣지 않음 (판정에 안 씀)

### D. 이상지질혈증 진단 여부 (설문) — 우선 낮음
- 대사증후군 기준표(데이터셋 진행 상황 8장): 원 기준의 "이상지질혈증 약 복용"이 설문에 없어서 **중성지방·HDL은 수치로만 판정** 중 → 약으로 수치가 정상인 사람은 놓침
- 혈압·혈당은 "진단 여부"로 약 복용을 대신하기로 했으니(진단 없이 약 먹는 사람 0명), **같은 방식으로 이상지질혈증도 진단 여부 1문항**이면 기준이 완성됨
- 모델 입력엔 안 넣음 (성은님 6-2 "다른 질환 진단 넣기 → 제외"와 같은 이유. 참고로 내 분석에서도 고혈압은 방향이 뒤집힘: 표준화 오즈비 0.87)

### E. 임신 중 여부 (여성만) — 우선 낮음 (안전)
- 모델 학습에서 **임신부를 뺐음**(데이터셋 진행 상황 5-1) → 임신 중인 사용자는 학습 범위 밖
- 임신 중엔 체중·혈당 해석도 달라 BMI 기반 예측이 맞지 않음 → "예"면 예측 대신 일반 안내
- 성별이 여성일 때만 표시, 재설문 O

hdl_cholesterol smallint [null, note: 'mg/dL, 대사증후군 기준 남 <40 / 여 <50']
