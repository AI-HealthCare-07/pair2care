# 사용자 페르소나

## 1. 당뇨병이 걱정되는 최민석

**① 누구** · 43세 제조업체 영업팀 과장. 오전 7시에 일어나 8시에 출근하고, 외근이 많아 점심은 국밥·짜장면처럼 빨리 나오는 메뉴로 먹는다. 퇴근이 늦어 저녁은 9시 넘어 먹고 11시쯤 바로 잔다. 하루 대부분 차로 이동해서 걸음 수가 3천 보 안팎이고, 주말엔 거의 누워서 쉰다.

**② 건강 상태** · 키 174cm, 몸무게 82kg(BMI 약 27). 줄자로 재본 허리둘레는 97cm로 남성 복부비만 기준(90cm)을 넘는다. 회사 건강검진은 바쁘다는 이유로 2년째 미뤄서 혈당 수치를 모른다. 어머니가 제2형 당뇨병으로 약을 드시고 있어 본인도 걱정은 되지만, 진단받은 병은 없다.

**③ 지금 불편한 점** · 배가 나온 건 알지만 그게 당뇨 위험으로 이어지는 수준인지, 그냥 살이 찐 건지 모른다. 병원에서 피검사를 받기는 번거롭고 결과를 듣는 게 겁난다. 뭔가 바꿔야 한다는 건 알지만 무엇부터 바꿔야 효과가 있는지 모르겠다.

**④ 기존 방법이 안 되는 이유** · 건강보험 앱의 질병 위험 예측은 검진 결과가 있어야 볼 수 있다. 혼자 헬스장을 등록했지만 야근과 외근에 밀려 몇 번 못 갔다. 유튜브 건강 정보는 "이것만 먹어라", "이건 절대 먹지 마라"처럼 말이 다 달라서 오히려 손을 놓게 됐다. 혼자 결심하면 아무도 확인하지 않으니 빠져도 티가 안 난다.

**⑤ 언제 우리 서비스를 켜는지** · 처음에는 퇴근길 지하철에서 5분 동안 설문(나이, 허리둘레, 운동, 수면, 음주, 식사 시간)에 답하고 당뇨 전단계 가능성을 확인한다. 결과 화면에서 바꿔볼 습관을 직접 고른다. 이후에는 저녁을 9시 전에 먹은 날 완료를 체크하고, 짝꿍인 같은 팀 동기의 체크를 확인한다. 일요일 밤에 한 주 기록을 보고 위험도가 어떻게 바뀌었는지 확인한다.

**⑥ 제일 필요한 기능** · 예측 + 대시보드 + 짝꿍 챌린지

- 피검사 없이 설문만으로 지금 내 당뇨 위험이 어느 정도인지 알고 싶다.
- "저녁을 9시 전에 먹으면", "주 3회 30분 걸으면" 비슷한 사람들의 위험도가 얼마나 달라지는지 숫자로 보고 직접 고르고 싶다.
- 같은 처지인 동기와 "저녁 9시 전에 먹기 주 4회"를 같이 정하고 서로 했는지만 확인하고 싶다. 허리둘레나 위험도는 보여주고 싶지 않다.
- 돌려 말하지 않는 직설형 안내를 원한다. 위험이 높게 나오면 검사를 받아보라고 분명히 말해주면 좋겠다.

## 2. 고혈압이 걱정되는 이수정

**① 누구** · 47세 회계팀 팀장. 오전 6시 반에 일어나 출근하고, 하루 8~10시간을 앉아서 일한다. 결산 기간(분기마다 2주)에는 밤 10시까지 야근한다. 바쁜 날 점심은 라면·김밥으로 때우고, 저녁은 집에서 남편과 찌개나 국 위주로 먹는다. 운동은 따로 하지 않는다.

**② 건강 상태** · 올해 회사 건강검진에서 혈압 134/86mmHg(고혈압 전단계 범위), 허리둘레 88cm(여성 복부비만 기준 85cm 초과)가 나왔다. 공복혈당은 98mg/dL로 정상이다. 결과지 종합 판정이 "정상B(경계)"라서 아직 병은 아니라고 생각하고 넘겼다. 고혈압 진단을 받은 적은 없다.

**③ 지금 불편한 점** · 결과지 숫자가 얼마나 위험한 건지 감이 안 온다. 짜게 먹는 게 문제라는 건 알지만, 남편과 같이 먹는 식탁이라 혼자만 메뉴를 바꾸기 어렵다. 다음 검진까지 1년 동안 무엇을 해야 하는지 모른다.

**④ 기존 방법이 안 되는 이유** · 병원에서는 "싱겁게 드시고 운동하세요" 한마디로 끝났다. 혼자 국물을 줄여봤지만 같이 먹는 사람이 그대로라 일주일 만에 원래대로 돌아갔다. 집에 혈압계를 사서 재봤지만 숫자만 쌓이고 그게 좋아지는 건지 나빠지는 건지 알 수 없었다. 식단 앱은 끼니마다 음식명과 양을 입력해야 해서 사흘 만에 지웠다.

**⑤ 언제 우리 서비스를 켜는지** · 검진 결과지를 받은 날 사진을 찍어 올리면 수치가 자동으로 입력되고 대사증후군 위험도를 확인한다. 저녁 식사 후 국물을 남긴 날 완료를 체크하고, 짝꿍인 남편의 체크도 확인한다. 주말 아침에 집에서 잰 혈압을 기록하고, 한 달에 한 번 허리둘레를 재서 입력한다. 야근하는 날 저녁 메뉴가 고민될 때 가끔 사진을 찍어 나트륨이 많은지 확인한다.

**⑥ 제일 필요한 기능** · 대시보드 + 짝꿍 챌린지 + LLM 추천

- 결과지 숫자를 일일이 입력하지 않고 사진만 올려서 내 위험도를 알고 싶다.
- 다음 검진 전까지 혈압·허리둘레·위험도가 어떻게 바뀌는지 그래프로 보고 싶다.
- 남편과 "저녁 국물 남기기 주 5회"를 같이 하고 서로 응원하고 싶다. 남편이 내 혈압 수치를 감시하는 구조는 싫다.
- 잔소리 말고 "이 메뉴는 나트륨이 하루 권장량의 절반 정도예요"처럼 사실만 알려주는 담백형 안내를 원한다.

## 3. 두 사람이 보여주는 서비스 구조

| | 최민석 | 이수정 |
|---|---|---|
| 걱정하는 질환 | 당뇨병 (전단계) | 고혈압 (전단계) |
| 시작하는 방법 | 설문 입구: 검진 결과 없음 | 검진 입구: 결과지 사진 입력 |
| 핵심 AI 기능 | 설문 기반 당뇨 전단계 예측 + 습관 시뮬레이션 | 검진 수치 기반 대사증후군 위험도 + 변화 그래프 |
| 짝꿍 | 같은 팀 동기 | 남편 |
| 짝꿍에게 보이는 것 | 습관 완료 여부만 | 습관 완료 여부만 |
| 안내 말투 | 직설형 | 담백형 |

## 4. 지키는 원칙

- 위험도는 "비슷한 습관을 가진 사람들의 데이터로 본 추정치"로 보여주고, 진단을 대신하지 않는다.
- 위험이 높게 나오면 말투와 상관없이 보건소나 병원 검사를 권한다.
- 짝꿍끼리는 수치를 공유하지 않는다. 짝꿍은 감시하는 사람이 아니라 같이 하는 사람이다.
- 식단 사진은 찍고 싶을 때만 쓰는 보조 기능이다. 안 찍어도 서비스가 돌아간다.
