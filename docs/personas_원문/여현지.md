"이 서비스를 누가, 왜 쓸까?" 사용자 1~2명 상상해보기 
   아래 6칸을 한 줄씩 채워오면 돼요 👇


   ① 누구: 나이 / 직업 / 생활 패턴
   ② 건강 상태: 어떤 만성질환이 걱정되는지 (진단 전 위험 단계 위주)
   ③ 지금 불편한 점: 건강 관리하려다 어디서 막히는지
   ④ 기존 방법이 안 되는 이유: 헬스앱·병원·혼자 결심 등이 왜 안 통했는지
   ⑤ 언제 우리 서비스를 켜는지: 하루 중 어떤 순간에 쓰는지
   ⑥ 제일 필요한 기능: 예측 / 대시보드 / 챌린지 / 짝꿍 / LLM 추천 / 식단 사진 / 알림 중


사용자_1
  ① 50대 전업주부, 식사는 규칙적인 시간에 하지만 운동량이 많이 부족
  ② 건강검진 결과, “고혈압전단계 수준, 공복혈당 정상과 경계 사이”를 진단받음
  ③ 평소 먹는 음식이 주의해야할 음식인지 매번 검색해서 확인하기 번거로움, 운동을 꾸준히 하기 힘듦
  ④ 식단을 지킨다고 해도 작심삼일, 혼자 기록을 작성해도 금새 흥미가 떨어짐, 병원은 2-3개월에 한 번 방문하기 때문에 일상 식단까지 피드백 받기 어려움
  ⑤ 공복 혈당과 혈압 기록, 식단 사진 기록할 때
  ⑥ 쿠션어를 탑재한 스트레칭(운동) 시간 알림(알림 +LLM 추천), 혈압 또는 혈당 기록을 작성하는 노트, 식단 작성 시 영양소 계산과 음식 주의 설명(식단 사진+ LLM 추천)




사용자_2
   ① 30대 대학원생, 식사시간도 불규칙하고, 간식 섭취가 잦으며, 회식도 잦은 편, 운동량이 많이 부족
   ② 혈압과 혈당 모두 정상 범위 내, 불규칙한 식사와 운동부족이 이어지면 위험이 커질 수 있어 관리가 필요한 시점
   ③ 영양소 불균형인 식사를 할 때가 많음, 운동을 꾸준히 하려고 하지만 포기할 때가 많음, 회식이 잦아 식단 조절이 깨짐
   ④ 혼자 세운 운동 계획은 논문 또는 수업 일정에 가장 먼저 밀림, 정상 수치를 유지하는 상태여서 병원에서 상담받기 어려운 부분이 존재함
   ⑤ 연구실에서 식사 대신 간식을 먹을 때, 식사 사진을 찍을 때(야식도 포함), 회식 일정이 잡혔을 때
   ⑥ 음주 스케줄 작성(회식 일정 입력 -> 식단 조절 알림), 짧은 운동 영상 또는 스트레칭 알림(알림 + 챌린지), 간식 대체 추천(LLM 추천), 식단 사진 업로드 시 영양 균형 계산
