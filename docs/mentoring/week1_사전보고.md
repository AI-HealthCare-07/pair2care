## 1. 주제
- 선택 주제: ① 만성질환 생활습관 챌린지 앱 (출제 기업 Talos)
- 서비스 한 줄 소개: **"혼자 하면 작심삼일, 짝꿍이랑 하면 습관"** — 고혈압·당뇨 위험 단계 사용자가 짝꿍과 함께 생활습관 챌린지를 하고, 위험도 변화를 직접 확인하는 웹 서비스
- 해결하려는 사용자 문제
  - 누가: 일하는 시간이 불규칙한 30~60대(사무직·자영업·현장직), 정상(예방)~경계 단계, 아직 진단 전
  - 어떤 상황에서: 건강검진에서 혈압·혈당 경계 판정을 받았지만 병원 관리 대상은 아님
  - 무엇이 불편한지
    - 무엇부터 바꿔야 할지 모름
    - 기록이 번거로워 며칠 만에 포기함
    - 혼자 세운 계획은 근무 일정에 밀려 흐지부지됨
    - 고정 시간 알림이 교대 근무·영업시간과 안 맞음
- AI로 푸는 지점
  - 위험도 예측: 설문(+선택 검진 수치)으로 고혈압·당뇨 위험도 참고값 계산 (직접 학습)
  - 예방 행동 추천: 공인 가이드 RAG 근거로 "오늘 해볼 한 가지" 제안 (LLM)
  - 식단 사진 분석: 음식 분류 → 영양 피드백 (경량 CNN 파인튜닝 + 비전 LLM 보조)

## 4. 주요 기능
- 필수
  - 위험도 예측: 설문만 / 검진 수치 포함 둘 다 동작, "진단 아님" 안내
  - 추적 대시보드: 집에서 잰 혈압·혈당·음주·운동량 그래프와 달성률, 위험도 추이
  - 생활습관 챌린지: "주 N회" 목표, 완료 체크, 연속 달성
  - **짝꿍 챌린지 (팀 핵심)**: 초대·수락, 같은 목표 공유, 짝꿍에게는 완료 여부만 보임 (건강 수치·위험도 비공개)
- 선택 (전부 구현 목표)
  - LLM 예방 행동 추천: 하루 1번 생성 후 저장, 근거 출처 표시
  - 식단 이미지 분류·영양 피드백
  - 알림: 앱 안 알림(SSE) + 웹 푸시(PWA), 4종(챌린지 리마인더·짝꿍·연속 달성·주간 리포트) + 사용자가 직접 만드는 리마인더
- 12/4 테스트 배포 범위: 가입(설문 + 선택 수치) → 위험도 예측 → 챌린지 만들기·완료 체크 → 대시보드 + 짝꿍 초대·완료 여부 보기

## 5. 기술 스택·아키텍처
- 프론트 React + Vite (PWA) / 백엔드 FastAPI, Tortoise ORM + aerich / DB MySQL 8, Redis
- 흐름: Client → Nginx → FastAPI → Redis Stream → AI 워커(Consumer Group) → Pub/Sub → SSE
  - 몇 초 걸리는 작업(LLM 추천, 식단 분류)만 워커로, 가벼운 예측 추론은 FastAPI에서 바로 처리
- AI: 예측 모델(XGBoost·LightGBM 후보, MLflow 기록), Claude API(개발 Haiku·배포 Sonnet), OpenAI 임베딩 + 하이브리드 검색(BM25+Kiwi, Chroma, 리랭커), CLOVA OCR(검토 중)
- 배포: AWS EC2 + Docker Compose (EC2 제공 예정, S3는 운영진 확인 중)
- 데이터: 국민건강영양조사 원시자료(질병관리청) 검토 중, 식단은 AI Hub 한국 음식 이미지 + 식약처 영양 DB 후보 (둘 다 확보 전)

## 7. 멘토님께 질문
- **결과지 OCR**: 검진 결과지 사진에서 혈압·혈당을 읽는 기능(CLOVA OCR + 사용자 확인)을 6주 안에 넣는 게 현실적인지, 아니면 직접 입력으로 두고 시간이 남으면 붙이는 게 나은지
- **예측 대상·데이터**: 고혈압·당뇨를 각각 예측할지, 대사증후군 하나로 할지. 국민건강영양조사로 설문 기반 예측을 할 때 주의할 점(타깃 정의·누수)
- **식단 이미지**: 경량 CNN 파인튜닝(30~50개 음식)을 메인으로, 신뢰도가 낮을 때 비전 LLM으로 보조하는 구조가 이 기간에 적절한지
- **위험도 변화 표시**: 실천 기록만으로는 "위험이 줄었다"고 말하지 않고, 재설문으로 재계산한 값이 내려갔을 때만 보여주기로 함. 이 방식이 서비스 신뢰도 면에서 괜찮은지
- **아키텍처**: 6명·6주 규모에서 Redis Stream 워커 분리가 과한지, 이 정도면 적당한지
- **웹 푸시**: 아이폰은 홈 화면에 추가해야 웹 푸시가 됨. 데모 때 이 제약을 어떻게 보여주는 게 좋은지
