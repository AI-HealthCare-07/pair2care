# 가상 사용자 (페르소나)

> 팀원마다 고혈압 1명·당뇨 1명씩 작성한 숙제 모음. 11/17 회의에서 대표 사용자 2명으로 묶음.  
> 원문은 [personas_원문/](personas_원문/)에 보관함.  
> 항목: ① 누구 ② 건강 상태 ③ 지금 불편한 점 ④ 기존 방법이 안 되는 이유 ⑤ 서비스를 켜는 순간 ⑥ 제일 필요한 기능

## 김지연 작성

### 1. 당뇨병이 걱정되는 김지은
- ① 34세 온라인 쇼핑몰 운영 담당자. 점심은 사무실에서 배달로 해결하고, 오후엔 달달한 커피를 자주 마심
- ② 건강검진에서 공복혈당 경계 범위 안내를 받음. 아버지가 제2형 당뇨병을 관리 중이라 본인도 걱정됨
- ③ 매일 먹는 메뉴에서 무엇부터 바꿔야 할지 모르고, 바쁜 날엔 늘 주문하던 음식을 고름
- ④ 식단 앱은 메뉴와 양을 하나씩 입력해야 해서 며칠 만에 그만둠. 검진 때 들은 식단 조언을 실제 메뉴 선택에 적용하기 어려웠음
- ⑤ 점심 먹기 직전 사진을 찍고, 다음 배달 주문에서 바꿔볼 한 가지를 확인함
- ⑥ 식단 사진 + LLM 추천. 평소 메뉴를 바탕으로 다음 끼니에 시도할 작은 변화를 하나씩 제안받고 싶음. 한 달 뒤 당뇨 위험도가 내려갔는지 그래프로 확인하고 싶음

### 2. 고혈압이 걱정되는 박성호
- ① 49세 시설관리 기사. 주야간 교대 근무, 야간엔 편의점·구내식당에서 끼니를 해결함
- ② 건강검진에서 혈압이 높게 나와 재측정을 권유받음. 아직 고혈압 진단은 받지 않음
- ③ 근무표가 바뀔 때마다 걷기 계획이 밀림. 하루 이틀 놓치면 다시 시작하기 어려움
- ④ 매일 저녁 7시 운동 알림은 야간 근무 중 확인하기 어려움. 만보기 기록은 근무 중 걸음 수에 따라 크게 달라져 계획을 지켰는지 한눈에 보기 어려움
- ⑤ 새 근무표가 나오면 걸을 수 있는 날을 정하고, 쉬는 시간에 10분 걷기 후 완료를 체크함
- ⑥ 짝꿍 챌린지. 동료와 주 3회 걷기 목표를 정하고 서로의 완료 기록을 보고 싶음. 재측정 전까지 고혈압 위험도 변화를 보며 동기부여를 얻고 싶음

## 여현지 작성

### 사용자_1 (50대 전업주부)
- ① 식사는 규칙적이지만 운동량이 많이 부족함
- ② 건강검진에서 "고혈압 전단계, 공복혈당 정상과 경계 사이" 판정
- ③ 평소 먹는 음식이 주의할 음식인지 매번 검색하기 번거롭고, 운동을 꾸준히 하기 힘듦
- ④ 식단을 지켜도 작심삼일, 혼자 기록하면 금방 흥미가 떨어짐. 병원은 2~3개월에 한 번이라 일상 식단 피드백을 받기 어려움
- ⑤ 공복 혈당·혈압 기록, 식단 사진 기록할 때
- ⑥ 부드러운 말투(쿠션어)의 스트레칭 시간 알림(알림 + LLM), 혈압·혈당 기록 노트, 식단 영양소 계산과 주의 음식 설명(식단 사진 + LLM)

### 사용자_2 (30대 대학원생)
- ① 식사 시간 불규칙, 간식·회식 잦음, 운동량 부족
- ② 혈압·혈당 모두 정상 범위. 생활습관이 이어지면 위험이 커질 수 있는 예방 단계
- ③ 영양 불균형 식사가 많고, 운동을 꾸준히 못 하며, 회식으로 식단 조절이 깨짐
- ④ 혼자 세운 운동 계획은 논문·수업 일정에 가장 먼저 밀림. 정상 수치라 병원 상담을 받기 어려움
- ⑤ 연구실에서 식사 대신 간식을 먹을 때, 식사·야식 사진을 찍을 때, 회식 일정이 잡혔을 때
- ⑥ 회식 일정 입력 → 식단 조절 알림, 짧은 운동·스트레칭 알림(알림 + 챌린지), 간식 대체 추천(LLM), 식단 사진 영양 균형 계산

## 이지희 작성 — 은퇴 부부 (원문: 가상 사용자 시나리오 제출용)

> 컨셉: "인생의 짝꿍이, 건강의 짝꿍이 되다." 진단 전 위험 단계의 은퇴 부부가 서로의 건강 짝꿍이 됨

### 혈당 관리가 걱정되는 65세 아내
- ① 자녀 독립 후 남편과 지냄. 혼자 먹을 땐 빵·떡·과일로 간편하게 해결, 근력운동은 안 함
- ② 공복혈당 110mg/dL(공복혈당장애 범위), 당뇨 진단은 아님. 탄수화물 위주·단백질 부족 걱정
- ③ 매 끼니 메뉴·양 고민이 번거롭고 운동은 며칠 만에 중단. 식사·혈당·운동 기록이 흩어짐
- ④ 검진 결과만으론 내일 뭘 먹고 어떻게 움직일지 정하기 어려움. 식단 앱 입력이 번거롭고 혼자 결심은 오래 못 감
- ⑤ 아침 알림으로 추천 식단·부부 챌린지 확인, 식후 사진 올리고 AI 인식 결과 직접 수정, 저녁에 공동 달성률 확인
- ⑥ 짝꿍 챌린지(남편과 식사·산책), 큰 글씨·버튼 대시보드, LLM 식단·활동 추천, 사진+직접 수정 식단 기록, 혈당·체중·컨디션 선택 기록과 그래프

### 혈압과 활동량이 걱정되는 66세 남편
- ① 은퇴 후 활동량 감소, 친구 모임·술자리가 낙. 아내와 함께하는 활동 부족
- ② 혈압 135/85mmHg(고혈압 전단계 범위 가능), 확진 아님. 음주·짠 안주·운동 부족 걱정
- ③ 술자리를 끊기보다 줄이고 싶지만 실천이 어려움. 같은 걷기 코스는 지루하고 날씨 나쁘면 쉼
- ④ 생활습관 개선 권유만 받고 구체적 계획이 없음. 혼자 세운 절주·운동 목표는 오래 못 감. 배우자와 성취를 나누고 싶음
- ⑤ 아침에 걷기·절주 목표 확인, 측정한 날 혈압 기록, 산책 전 날씨·장소·후기 확인(악천후면 실내 운동), 저녁에 달성률·응원
- ⑥ 짝꿍 챌린지(함께 걷기·건강한 식사), 걷기·절주·혈압 대시보드, LLM 활동 추천, 혈압·체중·컨디션 기록 그래프, 시간 설정 알림

### 추가 아이디어 (지희님 제안, 구현 확정 아님)
- 날씨·산책 장소 추천과 이용자 후기, 일정 겹침 시 대체 시간 제안(승인 없이 변경 금지)
- 복약 기록·알림(처방받은 사람만, AI가 처방 임의 변경 금지)
- 가족 연결·효도 리워드(동의 시, 건강 수치 자동 공유 금지, 송금·결제 제외)
- 원칙: 벌칙보다 지속·성취·응원, 배우자가 감시자가 되지 않게 함

## 장성은 작성

### 당뇨병이 걱정되는 최민석
- ① 43세 제조업체 영업과장. 외근·차 이동이 많아 하루 3천 보, 저녁은 9시 넘어 먹고 바로 잠
- ② BMI 약 27, 허리둘레 97cm(복부비만). 검진 2년째 미뤄 혈당 모름. 어머니가 제2형 당뇨
- ③ 배 나온 게 당뇨 위험 수준인지 모름. 피검사는 번거롭고 무서움. 무엇부터 바꿔야 효과 있는지 모름
- ④ 건강보험 앱 위험 예측은 검진 결과가 있어야 함. 헬스장은 야근에 밀림. 유튜브 정보는 말이 다 다름. 혼자 하면 빠져도 티가 안 남
- ⑤ 퇴근길 5분 설문(나이·허리둘레·운동·수면·음주·식사 시간) → 당뇨 전단계 가능성 확인 → 바꿀 습관 직접 고름. 저녁 9시 전 식사한 날 체크, 동기 짝꿍 체크 확인, 일요일 밤 위험도 변화 확인
- ⑥ 예측 + 대시보드 + 짝꿍 챌린지. 피검사 없이 설문만으로 위험도, "주 3회 30분 걸으면 위험도가 얼마나 달라지는지" 숫자로 보고 고르기. 짝꿍에겐 수치 숨기고 완료 여부만. 직설형 안내, 위험 높으면 검사 권유

### 고혈압이 걱정되는 이수정
- ① 47세 회계팀장. 하루 8~10시간 앉아 일함, 분기 결산 2주는 야근. 점심 라면·김밥, 저녁은 남편과 찌개·국
- ② 혈압 134/86mmHg(전단계 범위), 허리둘레 88cm, 공복혈당 98(정상). 종합 판정 "정상B(경계)"
- ③ 결과지 숫자가 얼마나 위험한지 감이 안 옴. 남편과 같은 식탁이라 혼자 메뉴 바꾸기 어려움. 다음 검진까지 뭘 할지 모름
- ④ 병원은 "싱겁게 드세요" 한마디. 혼자 국물 줄이다 일주일 만에 복귀. 집 혈압계는 숫자만 쌓임. 식단 앱 입력 번거로워 사흘 만에 삭제
- ⑤ 검진 결과지 사진 → 수치 자동 입력 → 대사증후군 위험도 확인. 국물 남긴 날 체크·남편 체크 확인, 주말 혈압·월 1회 허리둘레 기록, 가끔 저녁 사진으로 나트륨 확인
- ⑥ 대시보드 + 짝꿍 챌린지 + LLM 추천. 결과지 사진만으로 위험도, 혈압·허리둘레·위험도 그래프, 남편과 "국물 남기기 주 5회", 남편이 수치를 감시하지 않는 구조, 사실만 알려주는 담백형 안내

### 성은님이 제안한 구조·원칙
- 두 가지 시작 방법: **설문 입구**(검진 결과 없음) / **검진 입구**(결과지 사진 OCR)
- 위험도는 "비슷한 습관을 가진 사람들의 데이터로 본 추정치", 진단 대신 아님. 위험 높으면 말투와 상관없이 검사 권유
- 짝꿍끼리 수치 공유 안 함, 완료 여부만 보임
- 안내 말투 선택 (직설형 / 담백형)
- 식단 사진은 보조 기능, 안 찍어도 서비스가 돌아감
